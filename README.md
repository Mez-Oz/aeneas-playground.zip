# Aeneas Playground (browser-based)

1. Push this folder to a GitHub repo.
2. Code -> Codespaces -> Create codespace (first build ~10-20 min; enable *Prebuilds* in repo settings to make later starts ~1 min).
3. In the terminal: `bash scripts/run_demo.sh`
4. Open `lean/RustDemo.lean` (generated) and `lean/Proofs.lean` to show the infoview.

Demo story: Rust -> Charon (LLBC) -> Aeneas (pure Lean) -> prove -> `lake build`.
